# Omareel 0.9.3

Record your screen, camera, and voice, then save locally or share a link from
storage you control. Optional Studio adds a finishing step for demos and
tutorials while keeping the everyday recording and sharing workflow intact.

## What's new

- Click-triggered zooms, Midnight/Paper/Minimal looks, backgrounds, frames,
  spacing, shadows, and canvas shapes. Style preferences persist between takes.
- Separate styled exports preserve the original and copy recorded audio without
  processing it again. Review the result before uploading.
- Camera visibility and quiet voice-ending cleanup improvements from Studio
  testing, plus the Quattro Stop/recovery fixes retained from 0.9.2.
- Older-FFmpeg support for file-based filter graphs, including the Ubuntu 24.04
  FFmpeg version used in CI.

## Security changes

Studio metadata and subprocess output now have hard byte ceilings. Recording
indexes are limited to 8 MiB with 1 MiB per entry; camera timestamps to 64 bytes.
Subprocess stdout/stderr are capped at 1 MiB/256 KiB, with an 8 MiB stdout limit
for library rewrites. Overflow fails the operation and reaps the child.

Library reads and writes use checked ownership, no-follow file handling, checked
locks, and atomic random temporary files. The library UI reads through the
bounded helper. Missing recording folders show an empty library on first use.
Camera/video inputs restrict FFmpeg to local-file protocols.

The previous explicit-install, runtime/settings safety, bounded logs/state,
plain-text UI, and Stop recovery protections remain included. Runtime does not
elevate privileges or install packages. Player pages request `noindex`, which
is not authentication or a guarantee against crawling or redistribution.

## Validation and limits

The security candidate passed 155 Python regressions, native Quickshell checks,
and both GitHub CI runs. Hadi reported successful local playback testing before
authorizing the release. Release metadata is checked in CI on the final commit.
See [testing and coverage](0.9.3-testing.md) for the evidence and CI links in
[PR #6](https://github.com/hadijaveed/omareel/pull/6).

Studio's preview is a still frame. Camera can be cropped during zoom. Portal
Window capture does not support click zoom. Exports use CPU-rendered SDR H.264
with a long edge up to 3840 pixels. Broader GPU, microphone, camera, and laptop
coverage remains unverified. Large indexes must be reduced or archived before
further library updates; these limits do not cap the video files themselves.

Marketplace verification of 0.9.3 requires a new exact-commit review. The prior
0.9.2 approval does not cover this release, and verification is not a security
audit. No Omareel account or subscription is required; storage provider charges
and access configuration remain the user's responsibility.
